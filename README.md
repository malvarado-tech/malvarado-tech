I'm Miguel Alvarado, a full-stack and AI engineer with a background in biotechnology. I design, build and operate internal platforms, data pipelines and LLM services for a biosafety consultancy, an AI safety nonprofit and a creative studio, mostly on React, Node, Postgres, Python and AWS, including retrieval-augmented generation over curated sources. I also have research experience in AI safety evaluation, and I like to learn by building: when a new model, tool or open-source repository comes out, I turn it into a working prototype.

Most of my work runs inside the organisations I build it for, so what is public here is a smaller set. [IBBIS Screen](https://github.com/malvarado-tech/ibbis-screen) is a web interface for IBBIS's open-source DNA-synthesis screening tool, so that synthesis providers and technicians can run a screen without the command line. [live-translation](https://github.com/malvarado-tech/live-translation) sends a speaker's audio through a realtime speech model and republishes the translation to listeners' phones. The AWS AI capstone adds managed AI services to a serverless store, and the AI4Math R project is a statistical analysis of LLM results on that benchmark. Research: [Do Repetitions Matter? Strengthening Reliability in LLM Evaluations](https://arxiv.org/abs/2509.24086) (preprint).
